纯语音控制的桌面绘图应用。用户只能通过语音指令完成绘图创作，不能使用鼠标或键盘。

## 功能

- 语音选择工具（笔/橡皮/线条）
- 语音选择颜色（50+ 中英文颜色名 + HEX）
- 语音绘制形状（圆/矩形/三角形/星形/直线）
- 语音编辑最近图形（移动/缩放/改色/选中）
- 语音绘画助手：记住图形语义并逐步补充细节
- 整幅画布模型创作：第一次语音让 Agnes 在白布中生成第一幅画，后续语音把上一张画布作为输入继续修改
- 逐步图生图：例如先说“画一棵树”，再说“树上长两个苹果”，模型会尽量保持原画不变，只补画新要求
- 传统几何/笔画兜底：圆形、矩形、线条、撤销、清空等控制仍由本地引擎执行
- 右侧作品步骤快照：每次语音完成后记录当前整幅画，便于回看创作过程
- 语音调整笔刷粗细
- 语音撤销/清空
- 语音 AI 生成图片（Agnes Image 2.1 Flash）
- 实时语音识别反馈面板
- 命令历史面板

## 技术栈

| 组件 | 选择 |
|---|---|
| 语言 | Python 3.10+ |
| GUI | PyQt6 |
| 语音识别 | OpenAI Whisper (base/small) |
| AI 绘图 | Agnes Image 2.1 Flash |
| 麦克风 | sounddevice + numpy |

## 安装

### 1. 安装 Python

确保已安装 **Python 3.10 或更高版本**。

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

如果需要本地 Whisper 模型，还需要安装 Whisper 的 C++ 依赖：
- **Windows**: 确保已安装 Visual C++ Build Tools
- **Linux**: `sudo apt install portaudio19-dev`

### 3. 配置 API Key（AI 生成功能需要）

```bash
# Windows (PowerShell)
$env:AGNES_API_KEY = "your-agnes-api-key"

# Windows (CMD)
set AGNES_API_KEY=your-agnes-api-key

# Linux / macOS
export AGNES_API_KEY="your-agnes-api-key"
```

## 运行

```bash
python main.py
```

## 创作模式说明

当前项目的开放式绘画由 Agnes 模型完成：本地代码不会为“大树、河流、苹果、鱼”等开放元素手写形状，而是把用户每一步语音整理成单色简笔画提示词交给模型。第一次请求使用空白画布生成，后续请求会把上一轮整幅画作为输入，让模型在原图基础上继续补画。

原创功能部分包括语音交互、命令解析、本地撤销/清空、作品时间线、整幅画布状态管理、模型提示词组织和失败兜底流程。Agnes Image 2.1 Flash、PyQt6、Whisper、sounddevice、numpy 等第三方依赖见 `requirements.txt` 和上方技术栈。
